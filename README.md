# みやぎライブEyes（Miyagi Bousai Eyes）

宮城県内の防災用ライブカメラ映像・水位観測所・ハザードマップを、地図および定点監視ボード上で一元確認できる総合防災ポータルサイトです。

- **本番公開URL**: [https://miyagi-bousai-eyes.pages.dev/](https://miyagi-bousai-eyes.pages.dev/)
- **お気に入り監視ボード**: [https://miyagi-bousai-eyes.pages.dev/favorites](https://miyagi-bousai-eyes.pages.dev/favorites)
- **独立カメラマップ（別窓）**: [https://miyagi-bousai-eyes.pages.dev/favorites_map.html](https://miyagi-bousai-eyes.pages.dev/favorites_map.html)

---

## 主な特徴と機能

### 1. メインポータル（`index.html`）
- **県内全域カメラの地図一元表示**:
  - OpenStreetMap上に河川（青）・道路（水色）・海岸（シアン）・市街地（緑）・ライブ動画（紫）のピンを直感的に配置。
  - ズームレベルに応じたスマートな表示切り替え（広域時はドット化、詳細時はカメラアイコン）。
- **川の流れ順（上流 ➡ 下流）ソート**:
  - 各水系（北上川、旧北上川、鳴瀬川、江合川、迫川など）のカメラを、キロ程（kp）および河口距離から自動計算し、**上流から下流への自然な水流順**で自動整列。
- **水系ごとの一括お気に入り登録**:
  - 各水系アコーディオンヘッダーの「⭐ボタン」を1クリックするだけで、その水系の全カメラを一括でお気に入り登録／解除可能。
- **総合防災情報連携**:
  - **ハザードマップ重ね合わせ**: 国土交通省の洪水浸水想定区域、土砂災害警戒区域、津波浸水想定の透過レイヤーをワンクリックで地図上に重畳。
  - **水位観測所マーカー**: 県内各地の水位観測所ピンから、リアルタイムの水位グラフ・警戒レベルへダイレクトアクセス。
  - **リアルタイム気象警報バー**: 気象庁APIと連携し、現在発令中の大雨・洪水・暴風警報をリアルタイム表示。
  - **7大圏域フィルター**: 仙台、石巻、大崎、栗原、登米、気仙沼、仙南の各地域ごとに素早くカメラを絞り込み。

### 2. お気に入り定点監視ボード（`favorites.html`）
- **自分専用の監視マルチビュー**:
  - 登録したお気に入りカメラだけを大画面グリッドで一覧監視。
  - **10分間隔の自動更新**: 静止画カメラは10分ごとに自動更新（カウントダウンタイマー付き）。手動即時更新も可能。
  - **ドラッグ＆ドロップ並べ替え**: カード上部のグリップを掴んで、直感的に自由な配置順へ並べ替え可能（ブラウザに自動保存）。
- **フロート型ミニマップ**:
  - 画面右下でお気に入りカメラの位置を把握できる連動ミニマップ。
  - **自由ドラッグ移動＆リサイズ**: ヘッダーを掴んで画面内のどこへでも移動、右下ハンドルで大きさも自在に変更（ヘッダーWクリックでリセット）。
  - **完全双方向インタラクション**: カードにマウスホバーすると該当ピンがオレンジ色に拡大発光。ピンをクリックすると該当カードへスムーズにスクロール＆点滅。
  - **位置ズレゼロ（0.00px）設計**: マーカー拡大アニメーション時もLeafletの位置座標を完全に保護する高精度2層構造。

### 3. 独立ウィンドウ型ミニマップ（`favorites_map.html`）
- **マルチモニター・デュアルディスプレイ対応**:
  - ミニマップ右上の「⧉（別ウィンドウで開く）」ボタンで、完全な独立ブラウザウィンドウとしてマップを分離。
  - サブモニターや別画面に配置しながら、親画面のカードホバー・ピンクリック・お気に入り追加解除が `BroadcastChannel` により**リアルタイムに双方向完全連動**。
  - 「ドック復帰」ボタンで、いつでも親画面内のフロートミニマップへ元通り格納可能。

## 使い方

### 基本的な使い方
1. ブラウザで [https://miyagi-bousai-eyes.pages.dev/](https://miyagi-bousai-eyes.pages.dev/) にアクセスします。
2. 気になる水系や地域のカメラの「⭐（お気に入り）」アイコンをクリックして登録します（水系ヘッダーの⭐で一括登録も可能）。
3. 画面上部の「⭐ お気に入り一覧」リンクから監視ボードへ移動します。
4. お気に入り監視ボードでは、カードをドラッグして見やすい順序に並べ替えます。
5. 必要に応じて右下のミニマップを開き、画面内の好きな位置へ移動・拡大したり、別ウィンドウとして切り離してマルチモニターで監視します。
